# Видео по текстовому запросу · React + TypeScript + Remotion

Исходники находятся в `video/`. Два формата: **1080×1920 (9:16)** и **1920×1080 (16:9)**, 30 кадров/с. Демонстрация — арабская буква **ب** на тёмно-зелёном фоне, **5 секунд**, плавное появление, движение и исчезновение.

## Установка и Studio

Требуется Node.js **24**. Используйте существующий checkout `/workspace/-`, без дополнительных worktree.

```bash
cd /workspace/-/video
export NODE_USE_ENV_PROXY=1
npm ci
export REMOTION_BROWSER_EXECUTABLE=/usr/bin/chromium
npm run dev -- --port=3000
```

В Codex Cloud Chromium уже установлен. Переменная `NODE_USE_ENV_PROXY` нужна Node.js для облачного HTTPS-прокси. `.npmrc` направляет кэш npm в доступный для записи `/tmp/codex-npm-cache`. Studio запускается без открытия системного браузера. После восстановления среды процесс Studio нужно запустить заново.

## Генерация по запросу

```bash
npm run generate -- 'Вертикальное видео 5 секунд с арабской буквой ب на тёмно-зелёном фоне'
npm run generate -- --render 'Горизонтальное видео 5 секунд, текст «بَ بِ بُ» на фоне #073b2c'
```

Первая команда сохраняет параметры в `out/prompt.json`; `--render` дополнительно создаёт **`out/generated.mp4`**. Генератор работает локально, без ключей и API. Это детерминированный разбор запроса для шаблона анимации текста, а не подключённая языковая модель и не генерация произвольных сцен.

Поддержаны: текст в кавычках `«…»`, `“…”` или `"…"`, арабская буква после слова «буква» / `letter` / `حرف`, вертикальный/горизонтальный формат (также `horizontal`, `landscape`, `16:9`, `أفقي`), длительность 1–60 секунд (`5 секунд`, `5 seconds`, `5 ثوان`) и цвет фона `#RRGGBB`. По умолчанию — вертикально, 5 секунд, фон `#073b2c`. Произвольные описания сюжетов нужно реализовать отдельными композициями либо подключить LLM в отдельной задаче.

## MP4, кадры и проверки

Выполняйте из `video/`, с `REMOTION_BROWSER_EXECUTABLE=/usr/bin/chromium`:

```bash
npm run render             # out/arabic-vertical.mp4
npm run render:horizontal  # out/arabic-horizontal.mp4
npm run still              # out/preview.png, кадр 60
npm run lint               # ESLint + TypeScript, включая CLI
npm test                   # тесты разбора запросов и сохранности огласовок
npm run build              # production bundle в build/
```

Экспорт использует Chromium и FFmpeg, поставляемый с Remotion; системный FFmpeg также доступен. MP4 кодируется H.264 / yuv420p для совместимости с обычными проигрывателями. На машине без Chromium установите поддерживаемый браузер через `npx remotion browser ensure` и оставьте `REMOTION_BROWSER_EXECUTABLE` unset, либо укажите путь к установленному Chrome. Потребуется сетевой доступ к серверу загрузки браузера.

## Арабский язык, RTL и огласовки

Локальный **Noto Naskh Arabic** хранится в `video/public/fonts/` вместе с лицензией SIL OFL. Шрифт загружается до захвата кадров, поэтому рендер не зависит от Google Fonts или системных шрифтов. Текст передаётся целиком: соединение букв, шадда, фатха, касра, дамма и другие комбинируемые знаки обрабатываются Chromium. Огласовки не удаляются и слова не разбиваются на отдельные анимированные буквы. Направление задаётся `direction: "rtl" | "ltr" | "auto"`; в демо используется RTL, в генераторе — автоопределение. Кавычки в запросе помогают точно сохранить арабскую фразу.

Проверка текста с огласовками:

```bash
npx remotion still src/index.ts ArabicHorizontal out/diacritics.png --frame=60 --props=examples/diacritics.json
```

## Настройка композиции

`video/src/Composition.tsx` содержит компоненты и регистрации обеих композиций. `defaultProps` задаёт текст, цвета, формат, направление и длительность. `video/src/video-spec.ts` проверяет параметры. Для точного управления передавайте JSON через `--props`:

```bash
npm run render -- --props=examples/diacritics.json
```

Формат из JSON определяет фактическое разрешение независимо от выбранного ID композиции. Для длинного текста добавляйте переводы строк; шаблон предназначен для коротких надписей до 240 символов. Новые ресурсы размещайте в `video/public/` и подключайте через `staticFile()`.

Исходники и lock-файл предназначены для Git; зависимости, сборка и результаты в `out/` исключены. Никакие другие репозитории для работы не нужны. Условия лицензии Remotion: https://www.remotion.dev/license
